Designed and developed a Web Application Firewall (WAF) capable of detecting and blocking common web attacks, including SQL Injection (SQLi), Cross-Site Scripting (XSS), and Command Injection. Built a machine learning-based SQL Injection detection module using TF-IDF vectorization and Logistic Regression on a dataset of over 30,000 SQL queries. Developed request filtering and validation mechanisms to inspect incoming HTTP requests in real time, preventing malicious payloads before reaching the web application. Contributed to data preprocessing, feature engineering, model development, backend integration, testing, and deployment. Strengthened practical skills in secure web application development, machine learning for cybersecurity, OWASP Top 10 vulnerabilities, HTTP request analysis, and attack prevention.
